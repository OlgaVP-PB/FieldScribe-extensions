🎤 FieldScribe offline-voice — demo

This page is a standalone test harness for the voice module. It is not FieldScribe, and it is not wired into the app - it just proves the microphone + on-device recognition works, so you can try it on a phone before integrating. Set MODEL_URL below first (see OFFLINE_VOICE.md). The first load needs internet to fetch the library and model; after that it runs offline.

Talk into the field. Tap the mic to start, tap again to stop.
